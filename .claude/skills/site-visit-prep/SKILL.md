# /site-visit-prep

Site: $ARGUMENTS

1. Read `../eco-mamae-playbook/SKILL.md`, then `references/discovery.md`, `references/buying-committee.md` and `references/positioning.md`. Read `deals/<slug>.md` if it exists.
2. Produce a one-screen brief the rep can read in the car:

### Before you go
Likely manager/role, one observation to make about the site, desired next step (from the weekly-planning rule). Segment risks to watch (e.g. occupancy for new developments, access windows in the CBD, hazardous streams at factories – if hazardous waste is possible, flag that it must go to compliance review, not a quote).

### 15-minute visit plan
The six-row table (0–2 … 13–15) with the playbook prompts, tailored to this site.

### The seven facts – capture sheet
Checklist of the seven facts; pre-fill anything already known, mark the rest `UNKNOWN`.

### Buyer map & access ladder
Buying-map roles with names if known; the access-ladder lines to use with whoever you meet first; the five decision-maker questions still open.

### Cost-of-inaction probes
The two playbook probes plus one tailored to this segment.

### Do not promise on site
Prices, start dates, collection windows, free bins/months, recycling percentages – all pending approval.

### Next action
One action · owner · date (normally: send same-day summary and book the decision conversation).
