# /objection

Objection: $ARGUMENTS

1. Read `../eco-mamae-playbook/SKILL.md` and `references/negotiation.md`; also `references/field-cases.md` for Cases 02, 06, 08 and 09 if price, budget, credit or start-date pressure is involved. Read the deal file if named.
2. Output:

### What's really behind it
One or two lines: which information is incomplete (scope mismatch, timing, cash flow, capacity, trust).

### Say this
The playbook response for the matching row, adapted to the situation, plus one clarifying follow-up question. If it matches a practice case, name it.

### If they push
A second line that **trades scope instead of conceding price** (different frequency, bag supply separated, phased start, deposit/billing structure pending approval). Never offer a discount, free month, credit term or start date as agreed – everything is "subject to approval / dispatch confirmation". Never attack the competitor; offer a like-for-like comparison.

### Close
Pick the most fitting of the three closes (choice, decision, next-step) and write it out.

### Next action
One action · owner · date.

If the "objection" is a request for a personal payment, switch to Case 07: decline script, neutral note, escalate, disqualify.
